按付款方式找入口

Claude 官网 Pro / Max，能登录

  1. 登录购买订阅的 Claude 账号，点击左下角姓名或头像，选择 Get help。
  2. 选择 Send us a message，点 Accept，再选 Claude Refund Request。
  3. 选择退款原因并完成资格检查；只有页面显示符合条件时，才能继续向支持团队提交处理。

Anthropic 条款说明，除条款明确允许或法律要求外，付款通常不可退款。资格检查不是退款承诺。

账号被停用，或暂时无法登录

账号被停用后仍可能能登录部分页面；若无法进入账号，在 Claude 帮助中心页面右下角打开消息入口，选择 I can't login。官方可协助核对账号、取消付费计划及检查退款资格。

准备好注册邮箱、账单付款方式及收据。若注册邮箱无法使用，官方退款说明建议用其他邮箱联系支持，并抄送原账号邮箱；不要把密码或验证码发给任何人。

Apple App Store 付款

由 Apple 处理的订阅款，只能由 Apple 审核退款。前往 reportaproblem.apple.com，选择“请求退款”并提交 Claude 订单。申请退款不会自动停止续费；还要在 Apple 订阅设置里单独取消。

Google Play 付款

Claude 官方说明：有效订阅需要联系支持检查资格；已失效订阅则提供 Google Play 账号邮箱或收据上的 GPA 订单号（格式类似 GPA.xxxx-xxxx-xxxx-xxxxx），让支持核对交易。后续退款资格由官方确认。

Claude API / Console 预付积分

API 预付积分与 Pro / Max 订阅不同。官方说明已购积分不可退款；如果账单信息有误或无法核对额度，请由 Console 管理员打开 Get help，向支持提交账单核查。无法登录时，可以通过官方帮助中心联系支持。

额外用量预付额度

先查看收据上的商品名称，区分额外用量、API 积分和订阅月费。额度无法使用或账单找不到时，准备发票、收据和付款凭证，请官方人工核对购买、已用、剩余及到期记录，并给出书面处理结果。

联系官方支持核对额度 ↗

团队席位、代购或渠道不明

  • 团队席位：先联系组织 Owner / Admin 核实席位、发票和付款方，由有权限的人向支持提交。
  • 代购或转售：向实际收款方申请退款并保留平台订单与沟通记录；不要把账号密码交给代购。
  • 付款渠道不明：先检查银行卡账单商户名称、应用商店订阅和邮箱收据，再选择退款入口。

提交前准备这些信息

  • 扣款日期、金额和币种
  • 付款收据、订单号或账单截图
  • Claude 注册邮箱；无法访问时说明
  • 封号/停用提示的原文或截图
  • 实际使用情况和遇到的问题
  • 你希望处理的事项：退款、取消续费、账号复核

只提交与核对账单相关的必要信息。请直接发给对应官方渠道，不要把收据、邮箱、银行卡资料或账号凭据交给本站或发在公开评论区。

退款、取消和申诉分开处理

  • 退款：请求审核已扣款项是否符合退款条件。
  • 取消续费：停止之后的自动续订；取消本身不代表已退回本期费用。
  • 账号申诉：对停用决定请求复核；官方申诉表需要登录被停用账号。

若无法登录，先从帮助中心选择“I can't login”联系支持。若银行争议正在处理中，Claude 支持暂不能同时处理退款；先与银行确认当前争议状态，不要为了催退款盲目撤销争议。

常见问题

账号被封后一定不能申请退款吗？

不能据此判断。先尝试登录；无法登录时，在帮助中心选择“I can't login”，让支持核对账号和付款信息并检查资格。是否退款由官方条款和审核结果决定。

申请退款会自动取消订阅吗？

不一定。Apple 退款不会自动取消订阅，需要另行取消；官网退款流程若符合资格，官方会在流程中处理计划取消与退款。确认账户或商店订阅状态，避免后续续费。

我想恢复账号，退款申请里怎么写？

账号复核和款项退款是两件事。按官方说明，申诉需要登录被停用账号提交；无法登录先联系支持。退款文案只描述扣款和退款诉求，不要把退款申请当作申诉表。

提交后一直没有回复，要再开一个工单吗？

官方建议同一问题保留一条对话；没有收到回复时，在原有消息或邮件线程里补充信息，不要重复新开相同请求。支持回复时间会因计划和问题情况不同而变化。

我正在向银行提出争议，还能同时要求 Claude 退款吗？

官方说明待处理的银行争议期间无法处理退款。你可以继续等待银行争议结果，或先咨询银行了解选择；本站不建议在未弄清影响前撤销争议。
